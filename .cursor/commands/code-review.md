# code-review

## 概要
変更したコードを確認し、以下の基準を満たしているか確認してください。
満たしていないコードは理由とともにユーザに示してください。
必ず全ての項目について確認するために、項目毎にプランを作成してください。
変更箇所に関しては以下のコマンドで取得してください。
```bash
git diff main
```

## 基準

- `./docs/coding_rules.md` に記載されているコーディングルールに従っているか否か
- `./docs/design_rules.md` に記載されている設計ルールに従っているか否か
- `./docs/develop_rules.md` に記載されている開発ルールに従っているか否か
