# コーディングルール

## 1. エラーハンドリング

### 1.1. カスタムエラークラスを作成する

- カスタムエラーは`Error`クラスを継承し作成する
- 全てのエラーはカスタムエラーとなっていることが好ましい
- 基本的に`Exception`をキャッチしてはならない
  - 考慮不足なエラーハンドリングを補完するためであれば例外として許可される

### 1.2. エラーは継承で表現する

- エラーの関係は継承により表現する

### 1.3. Errorをキャッチする

- 特定のカスタムエラーをキャッチする必要がない場合は、`Error`クラスをキャッチする

## 2. リポジトリクラス

### 2.2. トランザクション制御

- トランザクションの効率よりデータの完全性を優先すること
  - 例えば、DBとファイルが紐づいている必要がある場合、ファイル削除が完了されるまでDBのデータ削除を完了してはならない

### 3. コメント

- 基本的にコメントは使用しない
- 補足したい内容がある場合、モジュール・クラス・メソッド単位でDocstringを使用し記載する

### 4. Docstring

- 今の所必須ではない（今後必須にはしたい）
- reStructuredTextスタイルで記載すること
- 必ず型も記載する
