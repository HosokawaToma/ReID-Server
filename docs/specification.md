# 仕様書

## 1. システム概要

### 1.1. 目的

本システムは，複数カメラから送信される映像フレームを入力とし，人物の検出と再同定を行うことで人流データを収集することを可能とする．

### 1.2. 責務

- カメラフレーム画像から人物検出画像の生成
- 人物再同定に適切な画像のみに選別
- 人物再同定
- 人物再同定の精度評価
- カメラフレーム画像・人物検出画像・人流データの検索

---

## 2. 前提知識

### 2.1. カメラフレーム画像

クライアントがカメラで撮影した 1 枚の画像を指す．
クライアントはカメラ ID・ビュー ID ・撮影日時とともに画像を送信する．
カメラ ID とは，どのカメラで撮られたかを識別するIDである．カメラは動かさない想定であるため，地点としても扱う．
ビュー ID とは，どの場面で撮られたかを識別するIDである．本システムは使用しない．
機種や解像度は問わず，画像バイナリとして受け付ける設計とする．

### 2.2. 人物検出画像

カメラフレーム画像に対して物体検出（Object Detection）を適用し，検出された人物領域を矩形で切り出した画像である．
1 つの人物領域から 1 枚の人物検出画像が得られる．

### 2.3. 人物再同定

人物再同定（ReID）は，異なるカメラ・異なる時刻に撮影された人物画像が同一人物かどうかを判定する技術である．
本システムでは，人物検出画像から ReID モデルにより特徴ベクトルを抽出し，特徴量の類似度に基づいて同一人物とみなす．
これにより，複数カメラにまたがる人物の移動（人流）を時系列で把握できる．

ReID には CLIP-ReID を採用する．CLIP は画像と説明文の対応関係で事前学習された基盤モデルであり，言語的な意味理解に基づく汎用的でロバストな特徴表現を獲得している．
CLIP-ReID はこれを人物の特徴抽出に転用し，従来の CNN ベース手法と比較して頑健な照合性能を示すとされる．

### 2.4. 人物再同定に適切な画像

CLIP-ReID の入力としては，**人物単体が全身写っている画像** が理想である．照合精度を著しく低下させる画像は，次の 2 種類とみなす．

- **他者の混入**: 複数の人物が写り込んでいる画像．特徴量が複数人分混ざり，同一人物判定を誤らせる．
- **身体情報の欠損**: 全身が写っていない，または主要なキーポイントが欠損・低信用度の画像．特徴量が不十分となり照合精度が落ちる．

本システムでは，個体推定と姿勢推定を用いてこれらに該当する画像を選別し，「除外対象（ジャンク）」ラベルを付与する．選別を通過した画像のみを再同定の紐付けに用いることを想定する．

### 2.5. CMC 曲線

CMC（Cumulative Matching Characteristics）は，ReID の照合精度を表す指標の一つである．クエリ画像に対して，ギャラリ画像を類似度の高い順に並べたとき，**上位 k 位以内に正解（同一人物の画像）が含まれる確率** を Rank-k とする．

N 枚のクエリに対し，各クエリ q で上位 k 枚に正解が含まれていれば 1，含まれていなければ 0 を返す関数を \(f(q, k)\) とすると，Rank-k は次式で表される．

\[
\mathrm{Rank}\text{-}k = \frac{1}{N} \sum_{q=1}^{N} f(q, k)
\]

k = 1, 2, … に対する Rank-k をプロットしたものが CMC 曲線である．本システムの評価機能は，指定日のデータに基づいてこの CMC 曲線および各 Rank-k を算出する．

### 2.6. mAP

mAP（Mean Average Precision）は，ReID の全体的な照合性能を表す指標である．各クエリ q について，ギャラリを類似度順に並べたときの適合率の加重平均を AP(q) とし，全クエリで平均した値を mAP とする．

全ギャラリ数 M，正解画像数 G，上位 i 番目までの適合率 P(i)，i 番目が正解なら 1 否则 0 の指示関数 rel(i) を用いると，AP(q) は次式で表される．

\[
\mathrm{AP}(q) = \frac{\sum_{i=1}^{M} P(i) \times \mathrm{rel}(i)}{G}
\]

mAP は次のとおりである．

\[
\mathrm{mAP} = \frac{1}{N} \sum_{q=1}^{N} \mathrm{AP}(q)
\]

本システムの評価機能は，Market1501 と同一の考え方に基づくクエリ・ギャラリの定義で，指定日・試行に対する mAP を算出する．

## 3. 要件

### 3.1. カメラ非依存

本システムは，特定のカメラ機種・解像度・フレームレートに依存せず，Web API の契約を満たすクライアントから送信される画像であれば全て受け付ける．

### 3.2. 拡張性

本システムは，広範囲の人流を収集することを目的としている．
そのため多くのカメラに対応できるよう設計する必要がある．
そのためには，物体検出・選別・特徴量抽出・再同定といった推論処理の並列処理，DBに大量のデータが保存される想定の処理を実装する必要がある．

### 3.3. リアルタイム性

API は，カメラフレームの受信とジョブのキュー投入までを担当し，検出・選別・再同定の完了を待たずに応答する．
推論は非同期で行うため，厳密なリアルタイム応答は保証しない．一方で，ワーカー数の調整やキュー設計により，許容可能な遅延範囲で人流データを蓄積できるようにする．

## 4. 運用方針

### 4.1. カメラフレーム画像の受け取り

クライアントは，カメラ画像（1 フレーム分），カメラ ID，撮影日時，ビュー ID を Web APIに送信する．
サーバは受信内容を検証し，カメラフレームとして保存した上で，人物検出ジョブをバックグラウンドのキューに投入する．
API は受け付け完了を即座に返し，検出結果は非同期で反映される．

### 4.2. 人物検出画像の作成

キューから未処理のカメラフレームを取得し，物体検出（Object Detection）を実行する．
本システムでは YOLO（YOLOv11x）の Object Detection を用い，人物領域を検出して矩形で切り出す．
検出された各人物領域について 1 枚の人物検出画像を生成し，以降の選別・特徴量抽出・保存の対象とする．

### 4.3. 人物検出画像の選別

人物再同定の照合精度を保つため，人物検出画像に対して **除外対象（ジャンク）** の判定を行う．以下の 2 段階で実施する．

1. **個体推定（Instance Segmentation）**: 人物検出画像内の人物領域を画素単位で数える．
人物クラスのマスク数が **1 でない** 場合は他者が混入しているとみなし，除外対象ラベルを付与する．画像内に 1 人のみ写っている状態を担保する．
2. **姿勢推定（Pose Estimation）**: 主要キーポイント（鼻・目・肩など）の位置と信用度を推定する．
キーポイントが欠損している，または **全身キーポイントの信用度の平均が閾値未満** の場合は身体情報が欠損しているとみなし，除外対象ラベルを付与する．
閾値は 0.65 をデフォルトとし，設定で変更可能とする．画像内に対象の全身が写っている状態を担保する．

本システムでは YOLOv11x の Instance Segmentation および Pose Estimation を用いる．選別後も全画像を保存し，ジャンクフラグにより検索・評価時にフィルタする．

### 4.4. 人物検出画像の特徴量抽出

選別を通過した画像（および必要に応じてジャンク画像も）を ReID モデルへ入力する．
本システムでは **CLIP-ReID** を用い，人物検出画像から **特徴ベクトル** を抽出する．
抽出した特徴ベクトルは，PostgreSQL と pgvector を用いて保存し，近傍探索および類似度順のランキング取得に利用する．

### 4.5. 人物再同定

抽出した特徴量に基づき，既存のスナップショットと照合して **同一人物とみなすスナップショット群に同一の人物 ID を割り当てる**．
時系列・カメラ情報を考慮した紐付けアルゴリズムを用いる．ジャンクと判定された画像は，紐付けの対象から除外することを想定する．
人物検出画像，特徴量，カメラ ID，ビュー ID，撮影日時，人物 ID，除外対象ラベルをデータベースに保存する．

### 4.6. 人物検出画像に正解ラベルを割り当て

ReID の精度評価のため，人物検出画像（スナップショット）に **人手で正解の人物 ID（Ground Truth）** を付与する．
本システムは正解ラベルの検索・付与・一括割当・削除の API を提供する．あるスナップショットの正解 ID を，他の複数スナップショットに一括でコピーする操作も可能とする．
評価時には，この正解ラベルに基づいてクエリ・ギャラリを定義し，CMC および mAP を算出する．

### 4.7. 人物再同定精度評価

指定日（および試行番号）を指定し，Market1501 と同一の考え方でクエリ・ギャラリを定義した上で，**CMC 曲線（Rank-k）** および **mAP** を算出する API を提供する．
クエリは両方のカメラに映った人物から 1 人あたり 1 枚を選び，ギャラリはクエリと同一人物 ID かつ同一カメラ ID の画像を除外した集合とする．
類似度順にギャラリを並べ，Rank-k と AP(q) を計算し，全クエリで平均して mAP を求める．
ジャンクを含めた条件とジャンクを除外した条件の両方の結果を返却できることが望ましい．
