# コーディングルール

## 1. Docstring

- モジュール・クラス・メソッドには必ず記載する
- Docstringで記載する
- `#` を使用したコメントアウトでは記載しない
- 処理の中に記載しない
- 以下に記載しているようにreStructuredTextスタイルで記載する
```python
"""
一行目には短い簡単な説明文
二行目以降には詳しい説明文
本来あるべき仕様について記載する
:param [型] [引数名]: 引数の説明
:return [型]: 戻り値の説明
:raises [例外クラス名]: 発生する可能性のある例外とその条件
"""
```

## 2. エラークラス

- `srs/error.py` に定義しているエラークラスを使用してください

## 3. リポジトリクラス

- データベース上のデータの完全性は保証されるよう実装する
- データベース、ストレージ、Redis間でのデータの完全性は保証しなくて良い
- データ保存の優先順位はストレージ > データベース > Redisとする

## 4. 型

- 型定義との整合性が保たれる実装にしてください
- ロジック上の要不要を問わず、型定義上、矛盾のない実装にしてください
