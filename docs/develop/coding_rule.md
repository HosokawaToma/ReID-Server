# コーディングルール

## 1. Docstring

### 1.1. 概要

- モジュール・クラス・メソッドには必ず記載する
- モジュール・クラス・メソッド以外には記載しない

### 1.2. フォーマット

- reStructuredTextスタイルで記載する（以下例）
```python
"""
一行目には短い簡単な説明文

二行目以降には詳しい説明文

:param [型] [引数名]: 引数の説明
:return [型]: 戻り値の説明
:raises [例外クラス名]: 発生する可能性のある例外とその条件
"""
```
- 一行目の説明文
  - どのような振る舞いをするのかを記載する
  - 利用者向けに記載する
  - 実装内容を見ないことを前提に記載する
- 二行目以降の説明文
  - 正となる振る舞い・仕様を記載する
  - 実装者向けに記載する
  - この説明文を見ながら実装することを前提に記載する

## 2. エラークラス

- `srs/error.py` に定義しているエラークラスを使用してください

## 3. リポジトリクラス

- データベース上のデータの完全性は保証されるよう実装する
- データベース、ストレージ、Redis間でのデータの完全性は保証しなくて良い
- データ保存の優先順位はストレージ > データベース > Redisとする

## 4. 型

- 型定義との整合性が保たれる実装にしてください
- ロジック上の要不要を問わず、型定義上、矛盾のない実装にしてください
