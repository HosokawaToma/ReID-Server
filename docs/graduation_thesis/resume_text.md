1. 序論
    1. 大学で人の流れを把握できれば，運営・空間創設に役立つ
    2. 人流の収集方法は色々あるけど，大学校内レベルでなら複数カメラで収集するのが良い
        1. 都市レベルの方法には GPS や携帯電話の回線からでないと難しいが，これら方法にはデメリットがあり，大学校内でなら他にもっといい方法がある
        2. 街区や建物内レベルの方法には Wifi や複数カメラを使った方法があり，Wifi ではもう収集できないため，このレベルではカメラでの方法が一番いい
        3. 部屋内のレベルの方法には，単一のカメラを使った方法があるが，これでは広い範囲をカバーすることができないため，大学校内では選択肢から外れる
    3. ReID 技術のレビュー
        1. 複数カメラから人流を収集する方法として，画像情報から人物に一意の ID を割り当てる ReID 技術を用いる必要がある
        2. ReID モデルは色々あるが，現在は CLIP を用いた CLIP-ReID がいい
        3. ReID タスクに用いる画像データの質によって参照精度が大きく変わるため，実環境で ReID を使用するには収集画像のゴミデータ判別が必要
    4. 本研究の目的
        1. 提案手法を用いた場合と用いなかった場合でどれぐらい CLIP-ReID の参照精度が変わるのか検証
        2.  CLIP-ReID を使って大学の建物の内の人流を解析することが可能かどうかの検討
        3. 将来的に拡張可能で大学内でこれからも使い続けられるようなシステムの構築
2. 手法
    1. 実環境における ReID タスクのシステムについて説明
        1. カメラからの画像を入力とする．これによりどのようなカメラからでも人流解析に使用することができる
        2. YOLO の物体検出タスクでカメラ画像から人物のバウンディングボックス画像が得られる．
        3. 収集画像に対し CLIP-ReID モデルによる人物再同定を行う
    2. 提案手法
        1. YOLO の個体識別タスクでバウンディングボックス画像内に人物が 1 人のみ写っている画像以外をゴミデータとして ReID タスクから除外する
        2. YOLO の姿勢推定モデルでバウンディングボックス画像に全身が写っている画像以外をゴミデータとして ReID タスクから除外する．
