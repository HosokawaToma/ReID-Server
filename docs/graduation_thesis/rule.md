# 概要
- 卒業論文の作成にあたってのルールを記載する．

# 文章作成のルール
- 必ず日本語で文章を作成する．
- 必ず「。」ではなく「．」を使用する．
- 必ず「、」ではなく「，」を使用する．
- 数式は LaTeX の記法で記述する．
- 数式は $ で囲む．

# 方針
- 本題に影響しない部分は記述しない．
  - 例えば，WebAPIの実装の内容は本題には影響しないため記述しない．
  - 例えば，DBのテーブル情報は本題には影響しないため記述しない．
  - 例えば，Railsの使用有無は本題には影響しないため記述しない．
  - 例えば，Dockerの使用有無は本題には影響しないため記述しない．
  - 例えば，CI/CDの実装の内容は本題には影響しないため記述しない．
  - 例えば，ログの実装の内容は本題には影響しないため記述しない．
  - 例えば，テストの実装の内容は本題には影響しないため記述しない．
  - 例えば，デプロイの実装の内容は本題には影響しないため記述しない．
  - 例えば，モニタリングの実装の内容は本題には影響しないため記述しない．
- 本題に関係のある部分は詳細に説明する．
  - 例えば，YOLOという技術の説明は本題に関係のある部分であるため詳細に説明する．
  - 例えば，CLIPという技術の説明は本題に関係のある部分であるため詳細に説明する．
  - 例えば，Transformerという技術の説明は本題に関係のある部分であるため詳細に説明する．
  - 例えば，ReIDという技術の説明は本題に関係のある部分であるため詳細に説明する．

# 文章構成
- 以下のような構成で作成する．

1. 序論
2. システムの概要
3. 実験
4. 考察
5. 結論
6. 参考文献
